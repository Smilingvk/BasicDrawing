# 🎨 TypeScript Drawing App

A browser-based drawing application built with **TypeScript** and **HTML5 Canvas**. Features a full set of drawing tools, a color palette, undo/redo history, and the ability to save your drawing as a PNG.

[Software Demo Video](https://youtu.be/xaHaoar6QCE)

---

## Features

| Tool | Shortcut | Description |
|---|---|---|
| ✏️ Brush | `B` | Free-hand drawing with adjustable size & opacity |
| 🧹 Eraser | `E` | Erase to background color |
| 🪣 Fill | `F` | Recursive flood-fill — fills connected area |
| 💉 Eyedropper | — | Pick any color from the canvas |
| 📏 Line | `L` | Draw straight lines with live preview |
| ▭ Rectangle | `R` | Draw rectangles with live preview |
| ↩ Undo | `Ctrl+Z` | Step back through history |
| ↪ Redo | `Ctrl+Y` | Step forward through history |
| 📂 Load | — | Load an image onto the canvas (drag & drop supported) |
| 💾 Save PNG | — | Async export of canvas as a PNG file |

## How to Run

```bash
# 1. Install TypeScript
npm install

# 2. Compile TypeScript → JavaScript
npm run build
# This outputs dist/app.js which index.html references

# 3. Open in browser
# Option A — macOS/Linux
open index.html

# Option B — VS Code
# Install the "Live Server" extension, right-click index.html → "Open with Live Server"

# Option C — Python quick server
python3 -m http.server 8080
# Then visit http://localhost:8080
```

> 💡 **Watch mode**: Run `npm run watch` while developing — TypeScript recompiles automatically on every save.
